# Черновик задачи: первая версия Chekino

Статус: проектирование, не разрешение запускать реализацию.

Цель: принять название/ссылку, определить фильм, сохранить в общем каталоге,
вести общую очередь просмотра и раздельные оценки 1–5, предложить выбор на вечер.

Согласовано: личные чаты, общая очередь, общий факт просмотра по первой оценке,
раздельные оценки 1–5. Перед реализацией закрыть UX Telegram, режим /new,
источник метаданных и доступ двух участников.

## Критерии приёмки после согласования

- Доступ только двум приглашённым участникам; токены и личные данные вне Git.
- Фильм, добавленный одним, доступен обоим; повторная ссылка не плодит дубли.
- Неоднозначное название подтверждается пользователем с выбором года/типа.
- Карточка содержит название, год, Кинопоиск; личная и внешняя оценки различимы.
- Оценка сохраняется только для конкретного участника и может быть исправлена.
- Первая оценка помечает фильм просмотренным обоими и убирает его из общей
  очереди и /random. У второго остаётся карточка «ПРОСМОТРЕНО — ждёт твоей оценки».
  Оценка одного не подставляется за второго. Точное поведение истории сообщений
  и удаление карточки у оценившего согласовать с ограничениями Telegram.
- /random не предлагает исключённые согласованными правилами фильмы;
  пустая очередь обработана понятным сообщением.
- /new предлагает реально существующий фильм вне общего каталога, объясняет выбор
  и не выдумывает рейтинг/ссылку. Добавление требует явного действия.
- Перезапуск не теряет каталог, оценки и не повторяет обработанные события.
- Есть экспорт/восстановление базы и понятная инструкция развёртывания.

Набросок модели: произведение (canonical ID, название, год, тип), участник,
общий статус просмотра и персональная оценка, источник добавления, отображение в Telegram.
Стек, схема хранения и рекомендательный алгоритм пока не выбраны.
