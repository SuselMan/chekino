# Chekino: состояние реализации

Обновлено 22.10.2026 в сессии реализации задачи
[#1 — первая версия](https://github.com/SuselMan/chekino/issues/1).
Рабочая копия: `~/projects/chekino`, публичный репозиторий `SuselMan/chekino`.

## Реализовано локально

- Python 3.12 и SQLite без внешних зависимостей.
- Поиск названий с подтверждением года/типа; прямые ссылки Кинопоиска.
- Общий каталог без дублей, очередь, random, личная навигация и одна карточка на чат.
- Независимые оценки 1–5, просмотр при первой оценке, `/rate` для второго.
- Исправление своей оценки через карточку и дополнительный `/history`.
- `/new`: добавление, оценка без предварительного добавления, замена рекомендации.
  Исключены каталог и последние 200 показанных рекомендаций; предпочтения обоих
  учитываются по жанрам. Холодный старт — разнообразная рейтинговая подборка.
- Атомарная запись данных/дедупликации, повтор доставки карточек после сбоя,
  защита устаревших кнопок и чужого доступа. Локальная блокировка второго poller.
- SQLite online backup, JSON-экспорт, инструкции восстановления и приватной настройки.

## Проверено

Локальные автоматические проверки: `python3 -m unittest discover -s tests -v`.
Проверены сценарии двух участников, транзакционные повторы, одновременные записи
через два SQLite-соединения, восстановление backup и запрет посторонних.
В тестах Telegram и метаданные заменены заглушками; живой результат не заявляется.

Публичная OpenAPI-схема Kinopoisk API Unofficial прочитана 22.10.2026;
методы поиска и карточки существуют, нужен `X-API-KEY` после регистрации.
Источник и квота описаны в README. Действительный ключ не проверялся.

## Ограничения

Превью запрашивается через Telegram `link_preview_options`; отображение зависит
от доступности постера и клиента, требует живой проверки. Пустые разделы — текст
в той же карточке. При сбое между первой отправкой и сохранением message ID
возможен дубль карточки: Telegram sendMessage не имеет ключа идемпотентности.
Ограничение удаления входящих старше 48 часов сохраняется.
