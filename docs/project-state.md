# Chekino: состояние реализации

Обновлено 22.10.2026 в сессии реализации задачи
[#1 — первая версия](https://github.com/SuselMan/chekino/issues/1).
Рабочая копия: `~/projects/chekino`, публичный репозиторий `SuselMan/chekino`.

## Реализовано локально

- Python 3.12 и SQLite без внешних зависимостей.
- Поиск названий с подтверждением года/типа; прямые ссылки Кинопоиска.
- Общий каталог без дублей, очередь, random, личная навигация и одна карточка на чат.
- Независимые оценки 1–5, просмотр при первой оценке, `/rate` для второго.
- Шкала 1–5 сразу в карточке, без промежуточной кнопки «Оценить»; выбранный
  балл отмечен галочкой. Исправление нажатием другого балла.
- Кнопка «Каталог» и раздел `/history` убраны по просьбе владельца; сохранённые
  фильмы и оценки не удаляются. Старые команды раздела возвращают в очередь.
- `/new`: добавление, оценка без предварительного добавления, замена рекомендации.
  Исключены каталог и последние 200 показанных рекомендаций. Подбор заменён
  агентом GPT-6.1 Sol на основе обеих историй оценок; к карточке два коротких
  предложения с объяснением. Пачки сохраняются в приватной .sol.sqlite.
- Неточные названия/описания уточняет фоновый агент GPT-6 Luna; проверка API
  и подтверждение пользователя обязательны. Ввод при ошибке не удаляется.
- У Luna видны прошедшие секунды и этап проверки Кинопоиска. После проверки
  сразу полная карточка; несколько кандидатов листаются. Убраны повторные
  запросы по переводу при найденном оригинале. Luna использует effort=none
  и project_doc_max_bytes=0; живая проверка опечатки — 4,38 с (один замер).
- Атомарная запись данных/дедупликации, повтор доставки карточек после сбоя,
  защита устаревших кнопок и чужого доступа. Локальная блокировка второго poller.
- SQLite online backup, JSON-экспорт, инструкции восстановления и приватной настройки.

## Проверено

Локальные автоматические проверки: `python3 -m unittest discover -s tests -v`.
Проверены сценарии двух участников, транзакционные повторы, одновременные записи
через два SQLite-соединения, восстановление backup и запрет посторонних.
В тестах Telegram и метаданные заменены заглушками; живой результат не заявляется.

Публичная OpenAPI-схема Kinopoisk API Unofficial прочитана 22.10.2026;
методы поиска и карточки существуют, нужен `X-API-KEY` после регистрации.
Источник и квота описаны в README. Действительный ключ не проверялся.

## Живая настройка и оставшаяся приёмка

Конфигурация `~/.config/chekino/config.json` (0600) настроена приватно:
отдельный токен, два ID из основного бота, ключ метаданных. В Git их нет.
`getMe`/`getWebhookInfo` успешны, webhook не установлен. Работает отдельная
`chekino.service`, автозапуск включён. После изменения кеша служба перезапущена;
Codex и остальные сервисы не перезапускались.

Метаданные проверены настоящим API: «Интерстеллар» — правильный ID/год,
описание и постер; «Дюна» — несколько произведений с типом и годом.
Рекомендации отфильтрованы до фильмов/сериалов, телешоу исключены.
Исправлена пагинация: диапазон берётся из totalPages источника; при исчерпании
первых выбранных страниц проверяются остальные. Раньше диапазон 1–10 мог
целиком попасть за реальные 5 страниц и ошибочно показывать пустую подборку.
Повтор поиска и повтор подборки с теми же параметрами: 0 сетевых вызовов.
Компактные отчёты в игнорируемом diagnostics/.

Кеш бессрочный (решение владельца 22.10.2026), максимум 1 ГиБ SQLite-файла,
watched-first LRU, место физически возвращается FULL auto-vacuum.
Счётчик 400 попыток за скользящие 24 часа сохраняется при перезапуске и очистке
ответов. Временные кандидаты в основной базе не накапливаются; каталог/оценки защищены.
Постеры кешируются как URL, их изображения получает Telegram.

Инфраструктура: `~/projects/vps-infra/docs/chekino.md`, служба и ежедневный
таймер зашифрованного бэкапа. Бэкап создан службой, расшифрован в памяти,
восстановленная SQLite имеет integrity_check=ok. Ключ отдельно вне Git.
Внешняя копия ещё не настроена. Карточка бота добавлена в приватный реестр сервисов.

Видимость оценки партнёра согласована: скрывать до собственной.
AI-подбор использует реальные оценки; гарантировать совпадение вкусов нельзя.
Агенты работают через установленный Codex с текущей авторизацией, без API-ключа
OpenAI. Sol реально создал подборку, один вариант проверен Кинопоиском.
Luna реально исправила «интерстелар» до «Интерстеллар», ID 258687 проверен API.
Новые вызовы не блокируют обработку Telegram; исходный ввод остаётся до результата.

**Осталось:** ручная приёмка обоих живых Telegram-чатов, визуальная проверка
превью, очистки ввода и кнопок. В рабочую базу тестовые фильмы/оценки не добавлялись;
сообщения от имени участников не имитировались. Issue #1 пока не закрывать.

## Ограничения

Превью запрашивается через Telegram `link_preview_options`; отображение зависит
от доступности постера и клиента, требует живой проверки. Пустые разделы — текст
в той же карточке. При сбое между первой отправкой и сохранением message ID
возможен дубль карточки: Telegram sendMessage не имеет ключа идемпотентности.
Ограничение удаления входящих старше 48 часов сохраняется.
