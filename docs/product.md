# Chekino: первая версия

## Назначение

Общий Telegram-бот для двух участников, выбирающих кино и сериалы для совместного
просмотра. У каждого личный чат с одним ботом, каталог и очередь просмотра общие,
оценки личные. Это отдельный проект, не функция Codex-портала.

## Согласованные правила

- Название или ссылка на фильм/сериал → поиск произведения и карточка с Кинопоиском.
- Добавление одним участником делает фильм доступным обоим в общей очереди.
- Оценки: целые числа 1–5, по одной независимой оценке каждого участника.
- Первая сохранённая оценка означает, что фильм посмотрели оба: общий статус
  «Просмотрено», исключение из /queue и /random.
- Второй видит «ПРОСМОТРЕНО — ждёт твоей оценки» в своём разделе /rate.
  Его оценку не заполнять автоматически. После своей оценки фильм уходит из /rate,
  но данные и обе оценки сохраняются.
- Оценка партнёра скрыта до сохранения собственной (решение 22.10.2026).
- Открытие кнопок оценки и решение «посмотрим сейчас» не означают просмотр.

## Команды и карточка

| Команда | Поведение |
|---|---|
| /queue | Общая непросмотренная очередь, одна полная карточка с листанием ⬅️ ➡️ |
| /new | Новая рекомендация вне общего каталога: «В очередь», «Оценить», «Ещё» |
| /random | Случайный фильм из общей непросмотренной очереди |
| /rate | Просмотренные фильмы без оценки вызывающего участника, с листанием |

Это одна переиспользуемая карточка в каждом личном чате, не пять сообщений
на страницу и не список одних названий. Карточка: постер/превью, название, год,
короткое описание, ссылка на Кинопоиск, статус и личная оценка, если есть.
Кнопка «⭐ Ждут оценки · N» ведёт из очереди в /rate. Навигация персональная:
переключение страницы одним не переключает карточку другого.

/new не добавляет предложение в каталог автоматически. «В очередь» добавляет
его обоим. «Оценить» открывает 1–5 прямо на карточке; сохранённая оценка добавляет
произведение в каталог сразу просмотренным и оставляет второму запрос оценки.
«Ещё» заменяет предложение, не добавляя текущее.

## Чистота чата

Команды, навигация, новые рекомендации и оценка обновляют существующую карточку,
не создавая отдельные сообщения «добавлено»/«оценено». Свежие входящие ссылки и
команды можно удалять только после успешной обработки; при ошибке ввод не терять.
Пустой раздел отображается той же карточкой с понятным текстом и переходами.
Не обещать полное удаление старой переписки: deleteMessage ограничен 48 часами.
Источник: https://core.telegram.org/bots/api#deletemessage.
Если сообщение карточки вручную удалено, восстановить панель без потери каталога.
Mini App, группа и бесконечная лента карточек не входят в согласованную первую версию.

## Кеш метаданных (согласовано 22.10.2026)

Кеш бессрочный, на диске, ограничен 1 ГиБ. При переполнении удалять старые
неиспользуемые записи, начиная с просмотренных. Каталог и персональные оценки
не являются расходным кешем и сохраняются. У источника лимит 500 запросов;
локальный предохранитель оставляет запас: 400 попыток за скользящие 24 часа.

## Открытые детали для исполнителя

- Источник метаданных/постеров и рекомендаций: проверить API, доступ и стоимость;
  не выбирать платную подписку без согласования. Не выдумывать ссылки и рейтинги.
- /new ориентирован на совместный просмотр: учитывать обе истории оценок;
  до накопления оценок нужен разумный старт, без обещаний точного угадывания вкусов.
- Видимость оценки партнёра согласована 22.10.2026: скрывать до собственной оценки.
- Сезоны сериалов, «Посмотрели без оценки», «Не интересно», фильтры, отдельный
  просмотр истории и кнопка «Смотрим» — расширения; не блокировать ими базовый MVP.
- Предлагаемые технические требования: дедупликация по canonical ID, подтверждение
  неоднозначного названия, исправление своей оценки, идемпотентная обработка.
- Telegram ID участников и токен передаются только приватно, не через публичный issue.
